# صانع الاستبيانات (موقع مستقل)

موقع لإنشاء الاستبيانات بالعربية (من اليمين إلى اليسار) والفرنسية والإنجليزية. **أي شخص يملك رابط الاستبيان يملؤه دون حساب.** أنت فقط تدخل بحسابك لإنشاء الاستبيانات والاطلاع على النتائج.

المكوّنات: Next.js 14 (الاستضافة وواجهات API) + Supabase (قاعدة البيانات وتسجيل الدخول). كلاهما له خطة مجانية.

## التشغيل خطوة بخطوة

### 1) قاعدة البيانات
1. أنشئ مشروعًا في https://supabase.com
2. افتح **SQL Editor**، الصق محتوى `supabase/schema.sql` وشغّله.
3. من **Project Settings > API** انسخ: `Project URL` و`anon public key` و`service_role key`.
4. من **Authentication > Providers > Email** يمكنك إيقاف «Confirm email» إن أردت الدخول فور إنشاء الحساب.
5. اختياري: من **Authentication > Sign In / Providers** عطّل «Allow new users to sign up» بعد إنشاء حسابك إن أردت أن تكون الوحيد القادر على إنشاء استبيانات.

### 2) محليًا
```bash
npm install
cp .env.example .env.local      # ثم املأ القيم
npm run dev                     # http://localhost:3000
```

### 3) النشر على Vercel (مجاني)
1. ارفع المجلد إلى مستودع GitHub.
2. في https://vercel.com اختر **Add New > Project** واستورد المستودع.
3. أضف المتغيرات نفسها من `.env.example` في **Settings > Environment Variables**.
4. اضغط Deploy. رابط الاستبيان سيكون بالشكل `https://موقعك/f/<معرّف>` ويظهر في تبويب «المشاركة» مع رمز QR.

### 4) المساعد الذكي (اختياري)
ضع `ANTHROPIC_API_KEY` في المتغيرات ليعمل: بناء الاستبيان بالمحادثة، ومن ملف، وتحليل النتائج، والترجمة. بدونه تعمل بقية الميزات. الاستخدام يُحاسَب على مفتاحك، ولذلك يوجد حد لكل مستخدم (`AI_HOURLY_LIMIT`، الافتراضي 40 طلبًا في الساعة).

## كيف يعمل

| الجزء | المكان |
|---|---|
| الواجهة كلها (محرر، ملء، نتائج) | `public/index.html` |
| منطق الأقسام والشروط والتصحيح (مشترك بين المتصفح والخادم) | `public/logic.js` |
| قراءة الاستبيان للمجيبين (بدون الإجابات الصحيحة) | `app/api/forms/[id]/route.js` |
| استقبال الردود والتحقق والتصحيح | `app/api/submit/route.js` و`lib/submit.js` |
| المساعد الذكي | `app/api/ai/route.js` |
| الجداول وسياسات الأمان | `supabase/schema.sql` |

- المجيب لا يلمس قاعدة البيانات مباشرة. كل شيء يمر عبر واجهات الخادم، فلا تصل الإجابات الصحيحة للاختبارات إلى متصفحه، ويُحسب الجواب على الخادم.
- المالك يقرأ ويكتب استبياناته وردودها فقط، بسياسات RLS في Supabase.
- «رد واحد لكل شخص» يعتمد على رمز يُحفظ في متصفح المجيب، وليس على هويته. من يمسح بيانات المتصفح أو يستخدم متصفحًا آخر يستطيع الرد مرة ثانية.
- «أقصى عدد للردود» والإغلاق بتاريخ محدد يُفرضان على الخادم.

## ما لا يوفره

- لا يوجد حاليًا حماية من الردود الآلية الكثيفة (spam). إن احتجتها فأضف Cloudflare Turnstile أمام `/api/submit`، أو حدًّا للطلبات من Vercel.
- حد الذكاء الاصطناعي محفوظ في ذاكرة الخادم، ويُصفَّر مع كل تشغيل جديد للدالة. للتحكم الصارم بالتكلفة ضع حدًّا للإنفاق في حساب Anthropic.
- تصدير PDF غير موجود. صدّر Word ثم احفظه PDF من Word.
